# Repository cleanup plan

Packaging/documentation only: preserve application, tests, algorithms, security,
models, datasets and research results. Do not commit, push, rewrite history or
change the index. Existing unrelated working-tree changes predate this task.

Initial measurement before audit files: **6,005,699,112 bytes** (6.006 decimal GB).
The saved automated before inventory includes the audit script and measures
6,005,704,340 bytes. `.venv` accounts for 5,716,728,044 bytes and `.git` for
54,931,673 bytes. Currently tracked working files use about 62.27 MB, excluding
substantial untracked prior work and required artifacts previously ignored by Git.

| Item | Action and evidence |
|---|---|
| `.venv/` | Remove from project; temporarily relocate for verification, then discard. Regenerable dependencies, mainly CUDA libraries. Preserve requirements and installed-version inventory. |
| Python bytecode, `__pycache__/`, `.pytest_cache/` | Remove and ignore; regenerated by imports/tests. |
| Root baseline/optimization test logs | Remove only after hashes match canonical logs under `results/optimization/`. |
| All five model artifacts | Retain and include in intended Git contents: vehicle RF, legacy login model, GRU weights/metadata, SKAB RF comparison. |
| All raw/processed data and SKAB manifests | Retain and include in Git: originals, licenses, split/scaler/checksum manifests and arrays used by tests/training/evaluation. |
| All research results, archives and profiles | Retain byte-for-byte. Duplicates can be intentional historical evidence. |
| Source, tests, existing scripts, requirements and existing docs | Retain byte-for-byte. |
| `.git/` | Preserve history; no LFS migration or rewrite. |
| README and `.gitignore` | Rewrite for actual implementation; save original copies in cleanup evidence. |

No required artifact needs compression or external relocation. Historical dataset
stage docs describe previous ignore rules; the new README/root ignore rules
describe current packaging. Demo keys are intentional prototype fixtures; scan
credential patterns without printing values. Historical profiling/provenance may
contain local paths: flag them rather than rewriting experimental evidence.

Validate the full test suite, syntax/imports, RF/GRU loading/inference, authenticated
laboratory and seeded scheduling comparisons, Streamlit startup/health, README
links and artifact presence. Write new evidence only under
`results/repository_cleanup/`. Compare SHA-256 hashes of every pre-existing
protected file. Measure logical file bytes, Git candidates and history separately.
